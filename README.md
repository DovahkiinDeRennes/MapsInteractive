# MapsInteractive

Créez une carte interactive, définissez des zones, ajoutez des marquages, etc.

## 🚀 Installation

1. Assurez-vous de lancer le projet sur un **serveur local utilisant le port 81** (très important).
2. Configurez la base de données **MySQL** :
   - Importez les données et tables fournies dans votre base.
3. Lancez le projet depuis votre environnement local.

## 🎉 Amusez-vous !

> **PS** : D'autres mises à jour (patchs) sont prévues dans les prochaines semaines ou mois.  
> **PS2** : Seule la création de polygones est actuellement utilisable et fonctionnelle.
