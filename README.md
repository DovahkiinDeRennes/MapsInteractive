# MapsInteractive

Créez une carte interactive, définissez des zones, ajoutez des marquages, etc.

## 🚀 Installation

1. Assurez-vous de lancer le projet sur un **serveur local en port 81** (important).
2. Configurez la base de données **MySQL** :
   - Importez les données / tables fournies dans votre base.
3. Lancez le projet depuis votre environnement local.
